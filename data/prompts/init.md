Write an AGENTS.md at the root of this project for the coding agents, you included, who work here later. crowbot reads it at the start of every conversation.

First look around: the README, the build and package files, how tests run, and enough of the code to see its layout and conventions. Then write down what an agent needs and cannot guess quickly:
- what the project is, in a sentence or two;
- how it is laid out, briefly;
- the exact commands to build, run, lint and test it;
- the conventions the code follows, and anything easy to get wrong.

Keep it short and concrete, a page rather than a manual, and only what you checked. If an AGENTS.md already exists, improve it and keep what is still true.
